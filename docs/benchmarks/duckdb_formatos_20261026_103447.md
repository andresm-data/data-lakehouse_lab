## Consultas

### q1_conteo

```sql
SELECT count(*) AS viajes
FROM trips
```

### q2_por_mes

```sql
SELECT year, month,
       count(*) AS viajes,
       sum(total_amount) AS total,
       avg(trip_distance) AS distancia_media
FROM trips
GROUP BY year, month
ORDER BY year, month
```

### q3_filtro_febrero

```sql
SELECT count(*) AS viajes,
       sum(fare_amount) AS tarifa,
       avg(tip_amount) AS propina_media
FROM trips
WHERE tpep_pickup_datetime >= TIMESTAMP '2025-02-01'
  AND tpep_pickup_datetime <  TIMESTAMP '2025-03-01'
```

### q4_top_zonas

```sql
SELECT PULocationID,
       count(*) AS viajes,
       avg(total_amount) AS total_medio
FROM trips
GROUP BY PULocationID
ORDER BY viajes DESC, PULocationID
LIMIT 10
```

### q5_por_hora

```sql
SELECT hour(tpep_pickup_datetime) AS hora,
       count(*) AS viajes,
       avg(trip_distance) AS distancia_media
FROM trips
GROUP BY hora
ORDER BY hora
```

### q6_propina_por_pago

```sql
SELECT payment_type,
       count(*) AS viajes,
       avg(tip_amount / fare_amount) AS propina_relativa
FROM trips
WHERE fare_amount > 0
GROUP BY payment_type
ORDER BY payment_type
```
